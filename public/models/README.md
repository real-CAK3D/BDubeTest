# 3D scans

Put `.glb` 3D scans here (for files over 4 MB, which the dashboard can't take).
Then in Dashboard > Products > (item) > Previews > 3D scan, paste the address,
for example `/models/flag-case.glb`.

Free phone apps that make a .glb from a walk-around video: Polycam, Scaniverse, KIRI Engine.
